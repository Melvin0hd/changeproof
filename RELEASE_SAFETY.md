# Scoped release safety review

Original F1 engine, adapters, validators, clients, MIT notices and redacted audit are pinned byte-for-byte. Decision Flow assets and the local server are unchanged. Existing Host/Origin/CSRF guards, request limits, loopback binding, both-provider preflight, redaction and one-attempt budgets remain intact. No backend rewrite or provider fallback is introduced.

Spatial V3 is a static optional bundle. Its packaging adapter replaces transport with fixed recorded data and removes non-recorded choices. It has no fetch/XMLHttpRequest or application-server route. It requires no Python backend, credential or inference for playback, and does not re-execute the original provider pipeline.

The scoped audit checks distributable files for known credential patterns, private user paths/personal mail, forbidden secret/runtime directories, accidental Git history and original evidence/license hashes. This is not exhaustive security certification, a penetration test or formal accessibility certification. No private Observer modules, gold data, keys, model weights or reference artwork are included.

Third-party excerpts retain attribution and rights; software MIT does not sublicense provider services or documentation. The film retains existing locally synthesized English narration, without new voice clone, music or reference artwork. The owner must confirm rights/contributors/eligibility and complete final watch/listen before upload. The main app is local single-user software, not safe public hosting.
