# ChangeProof / draft only

## Tagline
When new evidence challenges an old decision, trace the claim before changing course.

## Inspiration
A new price is not enough to overturn a supplier decision. Reviewers need the exact source, original assumption and unresolved conditions. ChangeProof separates successful AI extraction from sufficient decision evidence.

## What it does
An operator records a decision, usage and budget. Tavily retrieves excerpts; deterministic selection preserves relevant rows and qualifications. NVIDIA Nemotron on Nebius Token Factory extracts a strict structured claim. Schema, metadata, literal/numeric grounding and applicability checks precede an unchanged deterministic KEEP / REOPEN / ESCALATE adapter. Humans inspect reasons and export the audit before acting.

## Genuine demonstration
The hypothetical GitHub Actions baseline uses 100,000 potentially billable minutes and USD 700. A preserved real review contains three GitHub references from one publisher and one grounded USD 0.006/minute claim. Nemotron completed with 1,816 input and 204 output tokens, zero reasoning tokens. ESCALATE is justified by unresolved included minutes, contract applicability, effective date and excerpt omissions. USD 600 is illustrative arithmetic, not an accepted bill. Recorded playback and synthetic engine fixtures are explicitly separate from actual provider execution.

## Implementation
Standalone Python standard library, vanilla JavaScript, CSS/SVG, Tavily Basic and `nvidia/Nemotron-3_5-Lightning` through Nebius Token Factory. Decision Flow is the main UI. Optional Spatial V3 is a static recorded investigation, not a live backend integration. Melvenx / Observer Lab is our origin attribution; private Observer Core is neither shipped nor required.

## Challenges and technology feedback
Earlier responses exhausted tokens in reasoning or deviated from the extraction schema. Disabling thinking, JSON mode, narrower evidence and explicit contract instructions produced grounded output. Finish reasons, token usage and schema validation must be inspected rather than treating HTTP success as evidence quality. One historical run does not guarantee future provider compatibility.

## Accomplishment and limits
The source-to-claim-to-decision chain is inspectable, including a conservative genuine result. Fictional fixtures exercise all outcomes. Literal grounding is not truth verification; repeated references are not independent evidence. This is not autonomous procurement or a multi-tenant hosted service.
