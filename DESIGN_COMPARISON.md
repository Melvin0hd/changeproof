# Two presentations, one unchanged decision engine

## Recommendation

**Normal users: A / Decision Flow.** The previous decision stays in a separate left column. The green source-to-claim connection is quiet and easy to scan. The budget and the required human action are more prominent than implementation details.

**Video: B / Evidence Lens.** Three recorded references pass through a central inspection lens to one claim. Cyan indicates the evidence path; amber marks unresolved applicability. The original decision becomes a compact horizontal context bar. This makes the investigation visible in a short recording without imitating TwinTrace.

**Useful combination:** use A as the default application and B for the evidence-inspection segment in the film. Both routes remain independently launchable; no hybrid third design is needed. The selection remains a human creative decision, not a measured user-preference result.

## What is shared

Both use the frozen F1 Product, schema, extractor, grounding checks, pricing guard and KEEP / REOPEN / ESCALATE adapter. Shared presentation code consumes their actual audit contract. Editing the synthetic budget changes the engine result; classifications are not selected from the page title.

Recorded provider evidence, synthetic controls, mocked QA and newly authorized live attempts have separate visible labels. Playback uses a cached record and makes no provider request. Live mode is disabled by the ordinary launcher. When separately enabled, its existing preflight, one-attempt budgets, process-memory credentials and explicit user confirmation remain in force.

## Motion and meaning

- Source: the document represents source text already present in the selected record.
- Claim: the relevant exact row is highlighted; the interface shows one claim, not multiple invented extractions.
- Impact: the rate is compared with the earlier assumption.
- Result: ESCALATE keeps unresolved scope visible, with no success celebration.

The 3.6-second sequence is editorial playback, not measured provider latency. MP4 previews retain actual browser capture timing. Skip and reduced motion reveal the result immediately. Replay does not recompute the review. Live steps are not streamed by this engine; only actual waiting/completion/error states are displayed.

The provided images informed composition and hierarchy only. Neither reference image, its artwork nor its garbled placeholder text is distributed. Document geometry and connections are original; icons retain Lucide's ISC notice.
