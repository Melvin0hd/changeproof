# ChangeProof / Judge demonstration

ChangeProof checks whether new source evidence may invalidate an assumption behind an earlier supplier decision, without inventing certainty.

## Start in under ten minutes

Install Python 3.12 or newer. There are no pip dependencies. Unzip the candidate and double-click START_DESIGNS.cmd on Windows. Alternatively run:

```text
python -B design_server.py --port 8901
```

Open http://127.0.0.1:8901/design_a_decision_flow/ or http://127.0.0.1:8901/design_b_evidence_lens/ . Use another free port if needed. Each design's own launch.cmd starts its own local server. Stop with Ctrl+C in its terminal. Do not expose this loopback server to the internet.

## Genuine recorded review

Leave Recorded provider evidence selected. Inspect the hypothetical GitHub Actions Linux 2-core x64 decision, 100,000 potentially billable monthly minutes and USD 700 limit. Review recorded evidence. The original October 19 record is hash-checked and revalidated offline before presentation.

The preserved Tavily response has three references from one publisher, not three independent confirmations. Nemotron on Nebius produced one exact USD 0.006/minute claim. The response completed with 1,816 input tokens, 204 output tokens and zero reasoning tokens.

The presentation's USD 600 multiplication is explicitly illustrative. The original decision engine accepted no numeric cost calculation. Missing effective date, excerpt omissions, included minutes and contract applicability justify ESCALATE. Inspect the original span, source URLs, dates, validation limitations and the unchanged audit. Export audit downloads the original record; its historical LIVE_TAVILY_NEMOTRON field is retained, not reclassified as a fresh call.

## Interactive controls, not a forced result

Choose Synthetic offline example. Lower fee produces KEEP, Budget crossed produces REOPEN and Missing conditions produces ESCALATE with the default USD 100 baseline. Edit the budget to USD 250 and review the Budget crossed example again: the actual engine now returns KEEP. These are fictional fixtures, not research about a real vendor. Recorded baseline fields remain read-only.

Use keyboard Enter on Review, native details disclosures, Escape to close a dialog, Reduce motion, Skip and Replay. All important information also exists outside the animation. Copy audit includes a selection fallback; Export audit does not depend on the clipboard.

## Optional future live use

No live call is authorized by this package. A reviewer with their own credentials and separate authorization can start `python -B design_server.py --enable-live --port 8901`, configure both keys through the existing masked local form, select Configured live review and explicitly confirm credit coverage. Both credentials must pass validation before Tavily. Maximum one Basic search, three results, one Nemotron request and 768 output tokens per process. No retry or mock fallback. The app cannot inspect billing settings. Never share owner keys or offer an unrestricted owner-funded endpoint.
